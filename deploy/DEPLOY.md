# Как открыть приложение вне дома

Сейчас адрес API зашит в сборку и указывает на Mac в домашней сети. Дома
работает всё, вне дома — только офлайновый кеш с плашкой «данные от …».

Ниже два пути. Первый — за десять минут и бесплатно, но Mac должен быть
включён. Второй — по-настоящему, без Mac.

---

# Путь 1. Tailscale: телефон видит Mac откуда угодно

Приватная сеть между твоими устройствами. Наружу ничего не торчит, портов на
роутере открывать не надо, адрес не меняется при смене Wi-Fi.

## Шаги

**1. Поставить на Mac.** Нужен пароль администратора, поэтому команду
выполняешь ты:

```bash
brew install --cask tailscale-app
```

**2. Запустить и войти.** Открыть Tailscale из «Программ», войти через Google
или GitHub. Аккаунт бесплатный, до 100 устройств.

**3. Поставить на телефон.** App Store → Tailscale → войти тем же аккаунтом.

**4. Узнать адрес Mac.** После входа на Mac:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale ip -4
```

Выдаст что-то вроде `100.101.102.103`. Он постоянный.

**5. Пересобрать приложение** на этот адрес — это делаю я, просто пришли адрес.

## Минусы

- **Mac должен быть включён и не спать.** Уснул — приложение отвалилось.
  Лечится в «Системных настройках» → «Аккумулятор» → запретить сон при питании
  от сети.
- Трафик идёт через домашний интернет: в роуминге зависит от его скорости.
- Ещё одно приложение на телефоне, которое надо держать включённым.
- Это не публичный доступ: показать приложение другому человеку не выйдет.

# Путь 2. Свой сервер

Работает всегда, Mac не нужен, можно дать доступ другим людям.

## Что вообще требуется

1. Машина с публичным IP (VPS).
2. Домен, указывающий на эту машину. **Обязателен**: Caddy выпускает
   сертификат проверкой по HTTP-01, а без HTTPS iOS запросы заблокирует.
3. Docker на машине — ставится автоматически из `cloud-init.yaml`.

## Вариант А. Hetzner — под него уже написан terraform

Самый короткий путь: `deploy/terraform/` поднимает машину, диск, файрвол
и раскатывает `docker-compose.yml` целиком.

**Цена:** cx22 (2 ядра, 4 ГБ) — около 4 € в месяц. Проверь актуальную цену
на сайте, тарифы меняются.

### Шаги

1. Регистрация на [hetzner.com/cloud](https://www.hetzner.com/cloud), привязка
   карты.
2. Проект → Security → API Tokens → **Read & Write**. Скопировать токен, его
   показывают один раз.
3. Домен: купить и в DNS сделать A-запись на IP будущего сервера. IP узнаётся
   после шага 5, поэтому на практике: создать сервер, потом прописать DNS,
   потом дождаться распространения (`dig +short твой.домен`).
4. Ключ SSH, если его нет: `ssh-keygen -t ed25519`.
5. Дальше terraform — это делаю я, от тебя нужны токен и домен.

### Минусы

- Платно, пусть и немного.
- Карта обязательна.

## Вариант Б. Бесплатно

Бесплатно **возможно**, но с оговорками, которые стоит знать заранее.

### Машина

**Oracle Cloud Always Free** — самый щедрый: до 4 ядер ARM и 24 ГБ памяти,
бессрочно. Для этого проекта с запасом.

Минусы, из-за которых это не «просто бесплатно»:

- Карта нужна для проверки личности, даже если списаний не будет.
- ARM-мощностей в популярных регионах часто нет: в ответ на создание машины
  приходит «out of capacity», и так может продолжаться днями.
- Простаивающие бесплатные машины Oracle оставляет за собой право забрать.
- Поддержки на бесплатном тарифе нет.
- **Terraform из репозитория не подойдёт** — он под Hetzner. Настройка руками
  через `docker-compose.yml`, шагов больше.

**Google Cloud e2-micro** — тоже бессрочно бесплатен в некоторых регионах США,
но 1 ГБ памяти на Postgres, Redis и API — впритык, понадобится swap. И до
Баку далеко: задержка заметная.

**AWS** free tier — только 12 месяцев, потом платно. Для «поставил и забыл»
не годится.

Про **Render/Railway**: бесплатные тарифы усыпляют сервис, а бесплатный
Postgres там удаляют через месяц. Для базы, которая должна жить, не подходит.

### Домен

Покупать не обязательно:

- **DuckDNS** (duckdns.org) — бесплатный поддомен вида `qiymet.duckdns.org`,
  с Let's Encrypt работает нормально. Минусы: зависимость от чужого сервиса,
  адрес выглядит несолидно.
- Домен `.xyz` или `.top` стоит порядка доллара за первый год — часто проще,
  чем бесплатный вариант.

`.az` — местный регистратор, дорого и с бумагами. Для теста не нужен.

### Итого про бесплатно

Полностью бесплатная связка существует: **Oracle Always Free + DuckDNS**.
Расплата — ручная настройка вместо terraform, риск не получить машину из-за
нехватки мощностей и отсутствие гарантий, что тариф не изменят.

Если цель — чтобы просто работало и не отвлекало, 4 € в месяц на Hetzner
экономят несколько часов возни.

# Что нужно от тебя

Для Tailscale — выполнить `brew install --cask tailscale-app`, войти на обоих
устройствах и прислать адрес из `tailscale ip -4`.

Для сервера — токен провайдера и домен. Аккаунты и оплату я не завожу: это
твоя карта и твои учётные данные.
