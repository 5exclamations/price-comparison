# qiymət

Сравнение цен в супермаркетах Азербайджана: Bazarstore, Bravo, Araz, SPAR, Neptun, Rahat.

## Что в папке

| путь | что |
|---|---|
| `CLAUDE.md` | контекст проекта. Подхватывается агентом автоматически, править осторожно |
| `PROMPTS.md` | одиннадцать промптов для сборки приложения, по порядку |
| `demo.html` | рабочее демо на живых данных, открывается файлом |
| `pipeline/` | сбор данных: коннекторы, матчинг, аудит, история |
| `match_queue.csv` | пары товаров на ручную проверку, отсортированы по уверенности |
| `promo_honesty.csv` | все акции с настоящей глубиной скидки против рынка |

## Начать

```bash
cd pipeline
python3 run.py fast     # обновить цены и акции, ~4 минуты
python3 run.py build    # пересобрать демо
open ../demo.html
```

База `pipeline/qiymet.db` уже заполнена: 57 459 позиций, 5 641 товар сравнивается
минимум в двух сетях. Полное описание сбора — в `pipeline/README.md`.

## Что дальше

Открыть `PROMPTS.md` и идти по нему сверху вниз. Промпт 0 уже вынесен в `CLAUDE.md`,
начинать с первого.

## Чего пока нет

Настоящей истории цен. Механика готова и проверена (`pipeline/history.py`), но
данных в ней на два снимка. История наберётся сама, как только сбор встанет на cron.
